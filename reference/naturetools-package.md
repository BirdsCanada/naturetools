# Tools for COSEWIC assessments using NatureCounts data

naturetools is an R package for calculating and plotting COSEWIC ranges
(IAO and EOO). It builds on the
[naturecounts](https://birdscanada.github.io/naturecounts/) package,
which provides data access, example data sets and tutorials.
